One glyph that stands for my AI agent: the octopus 🐙 — one mind, eight arms,
every arm doing a different job at once. It spawns subagents, scores candidates,
retries, iterates, and juggles parallel work around the clock.

`main.ts` writes the single emoji (U+1F419, 4 bytes, no trailing newline) to
`/output/entry.txt`.
